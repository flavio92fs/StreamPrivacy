## English

Windows x64 release. **Capture exclusion depends on the app, Windows and the capture method. It does not work with every app or guarantee zero visible frames.**

- Genuine **English and Italian interface**, including the main window, tray controls and capture-test guidance.
- Saved language selector with **English** and **Italiano** options; `--language en` and `--language it` launch options.
- Localized README screenshots showing the real interface in each language.
- Dark/light theme, multiple app checkboxes, remembered choices, optional Windows startup, tray operation and window recovery.
- Portable ZIP with adjacent `Data/settings.xml` and an offline per-user installer with uninstall support.
- Public source and original icon under the MIT license.

**Privacy:** no telemetry, analytics, outbound network connections, update checks or information sent to developers. Only local window/process metadata is processed to apply protection; preferences, including language, stay on the computer. Both translations are bundled and work offline. See [PRIVACY.md](https://github.com/flavio92fs/StreamPrivacy/blob/main/PRIVACY.md).

Download [the portable ZIP](https://github.com/flavio92fs/StreamPrivacy/releases/download/v0.2.5/StreamPrivacy-0.2.5-win-x64-portable.zip) or [the setup EXE](https://github.com/flavio92fs/StreamPrivacy/releases/download/v0.2.5/StreamPrivacy-0.2.5-win-x64-setup.exe) and check the attached `SHA256SUMS.txt`. Binaries are unsigned; checksums verify file integrity and are not a digital signature.

App detection, Windows API confirmation and interface-rendering tests do not certify actual Signal, Discord, OBS or other capture output. Before sharing private content, check a real recording or the video received by viewers.

## Italiano

Versione per Windows x64. **L'esclusione dipende dall'app, da Windows e dal metodo di cattura. Non funziona con tutte le app e non garantisce l'assenza di fotogrammi visibili.**

- **Interfaccia realmente in inglese e italiano**, comprese finestra principale, comandi vicino all'orologio e indicazioni della prova di cattura.
- Selettore della lingua salvato con opzioni **English** e **Italiano**; avvio anche con `--language en` e `--language it`.
- Schermate dei README nella rispettiva lingua, generate dall'interfaccia reale.
- Tema scuro/chiaro, selezione multipla con spunte, scelte memorizzate, avvio facoltativo con Windows, area icone e recupero della finestra.
- ZIP portable con `Data/settings.xml` accanto all'eseguibile e installer offline per il singolo utente con disinstallazione.
- Sorgenti pubblici e icona originale con licenza MIT.

**Riservatezza:** nessuna telemetria, analisi di utilizzo, connessione di rete in uscita, ricerca di aggiornamenti o informazione inviata agli sviluppatori. Il programma elabora soltanto in locale i metadati di finestre/processi necessari alla protezione; le preferenze, lingua compresa, restano sul computer. Entrambe le traduzioni sono incluse e funzionano offline. Dettagli in [PRIVACY.md](https://github.com/flavio92fs/StreamPrivacy/blob/main/PRIVACY.md).

Scarica [lo ZIP portable](https://github.com/flavio92fs/StreamPrivacy/releases/download/v0.2.5/StreamPrivacy-0.2.5-win-x64-portable.zip) oppure [l'installer EXE](https://github.com/flavio92fs/StreamPrivacy/releases/download/v0.2.5/StreamPrivacy-0.2.5-win-x64-setup.exe) e verifica `SHA256SUMS.txt` allegato. I binari non sono firmati digitalmente: gli hash controllano l'integrità dei file e non costituiscono una firma digitale.

Il rilevamento delle app, la conferma delle API Windows e i test di rendering dell'interfaccia non certificano il video effettivo di Signal, Discord, OBS o altre modalità di cattura. Prima di condividere contenuti privati, controlla una registrazione reale o il video ricevuto dagli spettatori.
